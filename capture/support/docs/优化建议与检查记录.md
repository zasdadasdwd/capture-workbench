## 后续建议（尚未实施）

### 2. 查询与写入争用先测量再拆锁（P2）

证据：`storage.py::list_flows()` 在 Store 全局 RLock 内执行 COUNT 和分页查询；`get_flow()` 在同一锁内读取正文文件，再到锁外解码。大量复杂过滤或慢磁盘可能增加写入等待，当前没有该场景的专项测量。

建议：用临时数据同时执行持续写入、筛选和大正文读取，记录写入等待、查询 P95 和丢弃事件数。确认瓶颈后再考虑只读连接、缩短锁范围或游标分页。

风险：直接把文件读取移到锁外，会与删除正文发生竞争；拆锁必须先定义删除和详情读取的一致性。验收：性能指标有可复现实测，且并发删除、读取和写入仍通过测试。

### 3. 历史目录容量统计缓存（P2）

证据：`backend/api/sessions.py::history()` 每次遍历每个归档目录及正文文件计算容量。历史数量和正文文件数越多，打开历史页的工作量越大。

建议：缓存已结束会话的容量摘要；删除时失效，外部手工修改数据后提供刷新动作。大列表采用分页，避免一次统计全部历史。

风险：目录修改时间不能完整反映深层文件内容变化；缓存需要明确刷新机制。验收：使用多会话、大量小正文文件的临时数据比较首次/重复加载，并验证删除后的统计。

### 4. 前端按职责逐步拆分（P2）

证据：本轮检查时 `web/app.js` 约 1827 行，`web/links.js` 约 1044 行，仍同时承载状态、请求、事件和渲染。

建议：按 API 客户端、筛选编辑器、请求列表、重放任务和设置面板渐进拆分。保持原生 ES 模块即可，先为选择请求、组合筛选、重放和窄屏布局补浏览器回归，再逐块迁移。

风险：共享状态和事件重复绑定容易导致重复请求、选择丢失。验收：宽屏/窄屏行为一致，列表更新不重置选择，事件与请求次数没有增加。暂不以文件行数作为改造成功标准。

### 5. 可复现依赖与开发检查入口（P2）

证据：`requirements.txt` 使用较宽的依赖范围；pytest/ruff 没有统一开发依赖入口。代码直接导入 zstandard 等包，部分依赖目前由其他包间接安装。

建议：明确运行依赖和开发依赖，在干净虚拟环境中验证；提供锁定版本文件或标准锁文件及统一检查命令。升级依赖单独进行，避免夹带到业务重构。

收益：第三方开发者更容易复现环境。风险：锁文件需验证目标 Python/系统平台，不能把本机全部 pip freeze 输出当作通用依赖。验收：新环境安装后完整测试、代理转发和 MCP 启动成功。

## 本轮检查边界

- 未删除或迁移真实抓包数据，未调用业务目标接口进行重放。
- 不修改第三方研究案例的代码风格；全目录 Ruff 发现研究目录中 4 个既有提示，运行模块的检查单独执行。
- 不根据源码推测就声称消除了所有性能问题；存储争用、历史规模和前端交互需要各自的压力/浏览器测试。
- 本轮没有重启正在运行的服务；Hook 快照改动需完整重启 `main.py` 后才会在实际服务中生效。

## 已落地的实现与验证

- 配置回滚：`backend/api/system.py` 保留旧设置快照。新代理启动失败时恢复原配置文件并重启旧代理；恢复也失败时，错误同时列出原始失败和恢复失败。两项专用测试验证真实端口占用后能恢复旧端口转发，以及受控的二次失败能正确报告。
- 生命周期：`backend/context.py` 在启动与服务运行外围使用 `try/finally`，依次尝试重放会话、分析进程、代理和存储收尾。多个异常合并报告，保留原始启动或服务异常。四项专用测试覆盖异常启动、服务体异常、回调移除任务及多步骤收尾失败。
- 日志公平读取：`backend/query_logs.py` 给每份现存日志预留尾部读取额度，当前日志获得更高权重，总额度仍为 2 MiB。新增两项回归，覆盖大 MCP 文件以及八份日志同时存在；该模块共五项测试通过。单条记录超过其分配额度时仍可能被截断丢弃，`limited` 会表示结果受限。
- Hook 模块快照：每次 `main.py` 启动固定 `startup.toml` 中的 Hook 模块集合，Web 与代理子进程使用同一集合；运行中修改 TOML 不会增删模块，代理因设置重启仍沿用该集合，完整重启 main 才会读取新的模块列表。开始新抓包只重建 Hook 实例。这里固定的是模块配置集合，不是插件源码内容；各进程启动时仍从磁盘导入代码，因此运行期间不要编辑插件源码，源码修改需完整重启 main。失败导入会回滚本次 Hook 注册和相关导入缓存，不承诺撤销用户代码的任意外部副作用。新增失败导入后修复并重试的测试覆盖注册表清理与重试恢复。

这些修复不构成无限吞吐或绝对故障恢复保证。旧配置无法写回、旧端口被其他程序占用时，会报告恢复失败；操作系统强制杀死进程仍无法执行 Python 收尾逻辑。
